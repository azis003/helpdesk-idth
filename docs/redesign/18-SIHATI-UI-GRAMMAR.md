# SIHATI UI Grammar

Katalog ini mendefinisikan grammar konseptual SIHATI. Ia tidak membuat Blade component, CSS class, Tailwind token, JavaScript behavior, atau final design system. Nama `SIG-*` adalah identifier spesifikasi, bukan API component.

Semua pattern tunduk pada `17-SIHATI-DESIGN-DIRECTION.md`, contract freeze, server-side authorization, enam role, current-Approver assignment, Team Chair safe projection, dan implementation hold. “Manual prerequisite” berarti bukti harus tersedia **sebelum implementation pattern tersebut**, bukan sebelum dokumen ini direview.

## Reading Rules

- **Contract sensitivity** menilai risiko route/form/query/modal/data behavior jika presentation diubah.
- **Role sensitivity** menilai risiko data/action leakage atau capability loss antar-role/variant.
- Related FRP/DEC adalah provenance prinsip; tidak ada source/token/asset Frappe yang disalin.
- Screens hanya menunjuk UI aktif. Dormant views dan no-active-trigger endpoints tidak menjadi destination.
- Setiap interactive pattern mempertahankan native/server fallback dan exact HTML/form contract existing.
