# SIHATI Component State Matrix

Matrix ini adalah state contract konseptual untuk SIG-001–SIG-040. Ia tidak membuat component API atau client state. `N/A` berarti state memang tidak berlaku atau tidak didukung baseline; ia bukan izin untuk mengarang behavior.

## State Rules

- `UNAUTHORIZED` tidak pernah dipresentasikan sebagai `DISABLED`. Action, field, destination, section, atau record yang tidak berwenang tetap absent atau menghasilkan response server yang benar.
- Hover hanya reinforcement; informasi/action tetap tersedia melalui text, focus, atau structure.
- Focus berarti `focus-visible`, bukan removal outline atau hover clone.
- Selected hanya digunakan bila route/query/control existing benar-benar mempunyai selection. Tidak ada row selection atau bulk state baru.
- Loading mengikuti request lifecycle existing; tidak ada skeleton/client fetch palsu untuk SSR.
- Success/warning/danger digunakan hanya bila pattern memang merender semantic outcome, bukan sebagai variasi dekoratif.
- Readonly berarti data yang authorized dapat dibaca tetapi tidak diedit; data forbidden tidak boleh dimuat lalu disembunyikan.

## Coverage

- SIG patterns recorded: **40/40**.
- Interactive patterns have explicit hover/focus/active/loading/unauthorized treatment where applicable.
- Semantic-render patterns have explicit success/warning/danger treatment where applicable.
- Unsupported states use `N/A`; no saved selection, bulk action, client sort/filter, fake async, or unauthorized-disabled state is introduced.
- Responsive state never changes route, query, payload, role, projection, policy, or workflow meaning.
