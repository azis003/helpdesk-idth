# Baseline Visual Issues

Dokumen ini merekam temuan W0.3 terhadap UI **existing**. Tidak ada item di bawah yang diperbaiki pada fase ini. Temuan berasal dari kombinasi source review, render HTTP terautentikasi terhadap fixture disposable, dan contract freeze. Browser runtime tidak tersedia, sehingga setiap klaim yang membutuhkan piksel, viewport, pointer, atau keyboard ditandai sebagai **MANUAL CAPTURE REQUIRED** dan tidak dianggap telah diverifikasi secara visual.

## Evidence status

- **CONFIRMED — SOURCE/HTTP**: behavior terlihat pada source aktif dan/atau HTML runtime fixture.
- **KNOWN GAP**: gap sudah dibekukan oleh dokumen contract sebelumnya dan dikonfirmasi kembali.
- **MANUAL GAP**: belum ada bukti screenshot/runtime browser; ini bukan klaim bahwa layout pasti rusak.
- Kolom screenshot memakai `PENDING:` karena jumlah screenshot W0.3 adalah **0**. Filename tersebut merupakan target capture authoritative di `12-SCREENSHOT-INDEX.md`.

Severity menunjukkan risiko terhadap redesign/regression, bukan izin memperbaiki behavior.

## Freeze instruction

Issue register ini **bukan** approval untuk memperbaiki behavior. Item dengan `Functional change required = YES` harus masuk scope terpisah, mempunyai acceptance criteria, serta diuji terhadap route, authorization, validation, workflow, notification, audit, dan redirect contract. W0.3 hanya merekam baseline.
